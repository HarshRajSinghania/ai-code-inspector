# Contributing to AI Code Inspector

Thank you for your interest in contributing! Whether it's fixing bugs, improving docs, or adding new features, all contributions are welcome.

---

## 🚦 Current Project Status

- [x] **FastAPI Webhook Server**: Endpoint listening to incoming GitHub PR events.
- [x] **Security**: HMAC SHA-256 signature verification implemented.
- [x] **Async Processing**: FastAPI `BackgroundTasks` integrated for instant webhook responses.
- [x] **Gemini 1.5 Flash Integration**: Prompting and response structure built for code analysis.
- [x] **Deployment**: Web service live on Render.
- [⏳] **Active Issue**: Fine-tuning background execution and GitHub PAT permissions for posting PR review comments.

---

## 🚀 How to Contribute

1. **Fork** the repository.
2. **Clone** your fork locally:
   ```bash
   git clone [https://github.com/prachi137/ai-code-inspector.git](https://github.com/prachi137/ai-code-inspector.git)
   cd ai-code-inspector


  1. Create a feature branch:

   git checkout -b feature/your-feature-name

 2.Set up your virtual environment and dependencies:

   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt

3.Make your changes and verify everything works

4.Commit your changes with a descriptive message:
  
  git commit -m "feat: add amazing new feature"

5.Push to your branch:

 git push origin feature/your-feature-name

6.Open a Pull Request against the main branch:

 🐛 Found a Bug?
    If you encounter any bugs or unexpected behavior, please open an Issue detailing the problem.
